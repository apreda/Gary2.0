It used frozen synthetic mixed-league rows, five warmups, and 25 alternating
samples on Node 25.5.0; old/new outputs and total graded counts were checked.

The MLB request reduction uses mocked responses. It establishes eliminated
duplicate requests, not a measured production response-time improvement.

The original production check was also run read-only on the Desktop checkout.
It identified the scheduler in the correct folder and listed 19 deployed edge
functions, then printed **44 uncommitted changes** followed by a success message
and exit 0. That confirms the verification gap outside the synthetic tests.

check will report such a state as unverified; it does not commit other sessions'
work. Its existing edge timestamp comparison remains a heuristic, not deployed
source-content verification.
