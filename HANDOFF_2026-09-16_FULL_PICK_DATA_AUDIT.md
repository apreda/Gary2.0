## Root causes repaired

1. **Identity loss and ambiguous joins.** MLB odds/scout adapters now carry/resolve official team IDs; both MLB builders use exact team IDs and date/game identity, rejecting ambiguous doubleheaders rather than borrowing an adjacent game. Recent BDL box scores use the shared exact game/team join. Sox, shared college mascots, missing/ambiguous team names and player surname collisions cannot select the first convenient row. Savant lookups use MLBAM IDs or a unique complete name. Pitcher-tool crosswalks no longer match any player with a shared surname. MLB recent-game cutoff is part of cache identity.
2. **Wrong starter and missing zero-out appearances.** The BDL report used highest innings to infer the starter. It now uses `games_started` and includes pitchers who allowed damage without recording an out. Full pitcher names are retained. The June team K/9 calculation converts baseball innings through outs.
3. **Research process dropped the game object.** MCP context serialization excluded `game`, discarded long strings and removed repeated objects as though they were cycles. The complete serializable game and source strings now survive the handoff. Malformed/failure receipts return to the parent decision guard.
4. **Formatting dropped evidence.** MLB/NBA/general player tools preserve nested source fields, IDs, exact values, zeros, dates, season/sample qualifiers and returned records. NFL/NCAAF player projections retain the underlying records. Complete roster/stat packets accompany the readable report. Research handoffs no longer clip findings/numbers/context; both orchestrators retain earlier source messages. MLB articles/scoring detail no longer lose tails through arbitrary text caps. Intentional statistical windows and configured prop candidate/menu limits remain labeled and unchanged.
5. **Pagination and response nesting.** NFL rosters/season players, NCAAF active rosters and NBA reader paths now complete collection pagination. NBA season-average requests batch every requested ID instead of dropping IDs above 100. NBA usage reads the nested `stats` object. Offseason NBA fixes were covered by fixtures, not certified by a live paid-data read.
6. **Silent terminal source errors.** A decision-scoped integrity ledger records terminal BDL, StatsAPI, Savant and tool read failures even when old readers catch and return empty/null. It blocks model entry, successful return, and failed-data cache writes; required-data errors do not retry the decision on a different model. Shared transport failures mark every waiting decision. Genuine empty samples/boards remain distinguishable from malformed bodies, authorization errors and incomplete pages. Existing valid-cache TTLs are still honored; this is not a promise to refetch every datum on every tool call.
7. **MLB bullpen-news object/string mismatch.** June's news appendix tested `.length` on the response object, so successful text was omitted. It now reads the actual response text. This supersedes the prior handoff's preservation of that plumbing defect, under Adam's full-data repair instruction.
8. **NCAAF connected to an obsolete market provider.** Production still assumed BDL only had historical/opening props and called an inactive Odds API account. BDL now documents and serves current NCAAF markets on the paid GOAT plan. The active standalone and piggyback paths now use `bdlNcaafPropMarkets.js` as their primary connection: exact game/kickoff, current endpoint, current rosters, player IDs, prices, individual book attribution and original market records. No automatic provider substitution. **Do not ask Adam to reactivate The Odds API for this lane.** Legacy Odds API helpers remain only for historical fixtures/name normalization.
9. **Prop ticket identity.** MLB/NFL grouping uses player ID instead of name; conflicting name/ID histories fail. Invalid/missing provider lines no longer become 0.5. Integer milestones such as 300+ map to the equivalent over 299.5 ticket; genuine zero and half lines survive. Best price retains the offering book for each side. Stored-game-call read errors no longer masquerade as no previously published pick.
10. **Provider stream delivery.** Claude CLI output uses a UTF-8 decoder so a split multibyte character cannot corrupt a player's name. Provider context/output limits still exist and are not a guarantee of unlimited context; no application-side evidence eviction was reintroduced.
