## Why the IDs disappeared

`ballDontLieOddsService.getGamesWithOddsForSport` produces the odds-facing shape: team-name strings, time and markets. It does not attach MLBAM team objects. That shape predates September. The September 11 restoration of June's report (`67135fd4`) connected it to a reader that expects `home_team_data.id` and `away_team_data.id`. The September report it replaced resolved those IDs from the official schedule; June did not. The restoration retained current service imports without testing their complete input/output contracts.

For Giants at Cardinals / BDL game 5060044, the live chain proves it: raw BDL team IDs 24/26 → odds-shaped IDs absent → repaired MLBAM IDs 137/138. BDL IDs are a separate namespace and cannot be forwarded directly. No roster request failed at MLB: the missing IDs caused the code to skip the requests. Its empty-array handling allowed report construction and the roster-only naming instruction then produced anonymous roles.

The earlier runner repair (`c72a9f87`) resolves official team objects and verifies rosters before June runs; `308eaecf` adds the actual report/publication checks. This audit additionally fixes Arizona: MLB calls its `teamName` “D-backs” but exposes `clubName: Diamondbacks`. All 30 current BDL MLB team names now match exactly one official MLB team. These are primary-path repairs, with no alternate data provider added.

## Other defects found and repaired

1. **Recent results/rest/last-game detail were skipped by the same missing IDs.** The original two September 16 reports had no roster, recent games or rest schedule. All 15 September 15 MLB logs also show zero BDL box records and missing official last-game boxes. The repaired live report retrieves ten recent games for each club and actual official boxes.
2. **The recent-box request was independently broken.** June passed NBA-style `start_date`/`end_date` to BDL MLB. A live read returned the first 50 Cardinals games from 2000–2001. No current game joined, even after MLB IDs were restored. The new `mlbRecentBoxScores.js` requests supported `dates[]`, paginates, resolves the same home/away matchup and ET day (exact first-pitch time distinguishes doubleheaders), and groups records by exact game. Each club's recap reads only that club's players. The old date-only map could overwrite another team's game or combine doubleheaders. Missing/ambiguous matches or missing requested club boxes raise `required_data_unavailable`, without trying another brain or inventing copy.
3. **Savant values were stripped before June read them.** The shared September 8 metric policy removed xERA and its difference field. June's retained comparison consequently printed `undefined` and `NaN`. The later September 13 founder direction expressly preserves June including xERA. `getJunePitcherXStats` now retains the existing provider values in an isolated cache for June alone; default readers remain filtered. No xERA formula or interpretation wording changed. Live values: Molina 4.37; Liberatore 5.07, matching the provider CSV.
4. **Pitcher sample flags consumed the wrong row shape.** BDL's appearance rows did not contain the expected home flag and were counted as starts. Liberatore was incorrectly described as having zero home starts; the official log records 15. `mlbPitcherStarts.js` supplies actual regular-season starts with team/home identity from StatsAPI. Relief and spring appearances are excluded. The existing thresholds and warning text remain intact. The repaired report retains Molina's legitimate one-home-start flag and removes the fabricated Liberatore warning and appearance-based trade count.
5. **College-football records never reached their provider.** `fetchTeamProfile` called `getStandingsGeneric`, which intentionally returns `[]` for NCAAF. The dedicated `getNcaafStandings` already existed and was used elsewhere. The report now calls it with the actual conference/season, matches exact team and season, and reads `away_record`. September 12 logs contain 42 missing-record warnings in 21 of 22 jobs. Live Georgia/Alabama profiles now return the 2026 2–0 records from the 16-team SEC table. This is a caller-routing defect, not evidence of a BDL outage.

Provider references: [BDL MLB games](https://mlb.balldontlie.io/#games), [BDL NCAAF standings](https://ncaaf.balldontlie.io/#standings). Live response evidence is in the audit receipt below; documentation alone was not treated as proof.
